# HR-Attriton-Project
## Project Overview
This project focuses on analyzing employee data to understand the key factors that contribute to employee attrition (employees leaving the organization). The goal is to identify patterns and insights that can help improve employee retention.
## Objective
Understand why employees leave the company
Analyze important factors affecting attrition
Provide actionable insights for HR decision-making
## Dataset Description
The dataset contains employee-related attributes such as:
Age
Department
Job Role
Monthly Income
Job Satisfaction
Work-Life Balance
Overtime
Years at Company
Attrition Status
## Workflow
Data Collection
Data Cleaning
Handling Missing Values
Exploratory Data Analysis (EDA)
Data Visualization
Insight Generation
## Key Analysis Performed
Attrition distribution across departments
Impact of salary on attrition
Effect of overtime on employee retention
Relationship between job satisfaction and attrition
Experience vs attrition trends
## Tools Used
Python
Pandas
NumPy
Matplotlib
Seaborn
## Key Insights
Employees with overtime are more likely to leave
Lower job satisfaction increases attrition rate
Certain departments show higher attrition trends
Salary and experience have strong influence on retention
## Conclusion
This analysis helps HR teams understand the major reasons behind employee attrition and supports better decision-making to improve employee retention strategies.
